# CAPR-CLIP 实验计划

## 1. 实验原则

1. 每次实验只改变一个主要变量；
2. 完整验证集固定不变，候选模型不能重新定义自己的可信验证子集；
3. 第一轮使用单个固定种子快速筛选，入选方案再运行三个种子；
4. 同时记录竞赛主指标和长尾诊断指标；
5. 参数确定后，从官方权重重新初始化并使用当前阶段全部训练集重训。

## 2. 固定指标

| 指标 | 用途 |
|---|---|
| Full-val Top-1 | 主要模型选择指标，与线上指标一致 |
| Trusted-val Top-1 | 固定可信子集上的辅助诊断，不单独用于选模 |
| Macro Accuracy | 检查类别间是否失衡 |
| Head/Middle/Tail Accuracy | 定位长尾收益与损失 |
| Feature Drift | 微调特征与冻结 CLIP 特征的平均余弦距离 |
| Pseudo-label Coverage | 每轮接纳伪标签的样本比例 |
| Pseudo-label Class Entropy | 检查伪标签是否坍缩到头部类 |

头、中、尾类别应按照当前阶段训练集的类别样本量分位数固定划分，并将划分结果写入实验
产物，禁止在不同实验间改变。

## 3. 第一阶段：跑通基线

| 编号 | 配置 | 目的 |
|---|---|---|
| B0 | 冻结 CLIP + 余弦分类头 + CE | 验证数据、训练和提交链路 |
| B1 | 最后四层 Q/V LoRA + CE | 建立 PEFT 基线 |
| B2 | B1 + GCE | 判断鲁棒损失的独立收益 |

验收条件：结果文件格式正确；同一 seed 可复现；训练日志包含配置、Git commit 和数据 manifest
哈希。

## 4. 第二阶段：可信度估计

| 编号 | 配置 | 目的 |
|---|---|---|
| T1 | B1 + OOF 分类置信度 | 验证独立分类信号 |
| T2 | B1 + 留一原型间隔 | 验证全局类别结构 |
| T3 | B1 + mutual-kNN | 验证局部邻域结构 |
| T4 | B1 + 三信号类别内秩融合 | 验证完整初始可信度 |

除了最终准确率，还应检查：

- 各类别可信度分布是否异常集中；
- 尾部类别是否被整体判为低可信；
- 跨类别重复图是否获得较低权重；
- 三个信号之间的相关性，避免重复信号虚增置信度。

可在固定可信子集上人工注入 10%、20%、40% 的对称或近邻类别噪声，仅用于诊断可信度的
噪声检出率。该实验不参与最终模型训练。

## 5. 第三阶段：鲁棒微调

| 编号 | 配置 | 目的 |
|---|---|---|
| R1 | T4 + 连续可信加权 | 核心抗噪基线 |
| R2 | R1 + 自适应特征锚定 | 验证抗遗忘效果 |
| R3 | R2 + EMA 一致性 | 验证无标签一致性收益 |
| R4 | R3 + 严格门控软标签 | 验证标签修正收益 |
| R5 | R4 + 高可信原型约束 | 验证细粒度类间间隔 |

若某模块在三个种子中的平均收益小于波动范围，默认不进入主方案。

## 6. 第四阶段：长尾校准

| 编号 | 配置 | 目的 |
|---|---|---|
| L1 | 最佳 R 配置 + cRT | 主长尾方案 |
| L2 | 最佳 R 配置 + 弱 logit adjustment | 备选方案 |
| L3 | 最佳 R 配置 + 平方根采样 | 检查表示阶段采样策略 |

先分别比较 L1、L2、L3。只有独立收益明确时才进行组合实验，避免重采样、重加权和 logits
修正造成多重补偿。

## 7. 第五阶段：模型容量与分辨率

在算法主线固定后再比较：

| 变量 | 候选值 |
|---|---|
| LoRA 注入位置 | 后四层 Q/V；全部层 Q/V；后四层 Q/K/V/O |
| LoRA rank | 4、8、16 |
| 输入分辨率 | 224、288、320 |
| 裁剪范围 | `(0.70, 1.0)`、`(0.80, 1.0)`、`(0.90, 1.0)` |

分辨率实验需要同步记录显存、训练吞吐和推理耗时，最终选择应考虑复现资源限制。

## 8. 推荐执行顺序

```text
B0 -> B1 -> B2
          |
          v
T1/T2/T3 -> T4
             |
             v
R1 -> R2 -> R3 -> R4 -> R5
             |
             v
          L1/L2/L3
             |
             v
    LoRA 容量与分辨率搜索
```

若时间有限，优先完成 `B0 -> B1 -> T4 -> R1 -> R2 -> L1`。

## 10. 主方案进入标准

候选模块进入最终技术路线需要同时满足：

1. 三个种子的 Full-val Top-1 平均值提升；
2. 提升幅度大于随机种子波动或具有稳定方向；
3. Tail Accuracy 没有不可接受的下降；
4. 不依赖测试集统计或人工样本名单；
5. 训练和推理资源满足最终复现要求；
6. 删除该模块后能在消融实验中观察到一致退化。

## 11. 最终产物

- 完整配置文件与依赖锁定；
- 数据 manifest、类别映射和自动审计报告；
- 训练日志、验证指标和消融汇总表；
- 单一最终 checkpoint；
- `pred_results.csv` 及格式校验日志；
- 可从空缓存运行的训练和推理说明。
