# CAPR-CLIP 技术路线

## 1. 问题定义

任务是在训练标签含噪、类别间差异细微且部分阶段呈长尾分布的条件下，使用固定骨干
CLIP ViT-B/32 完成单标签图像分类。主要评价指标为 Top-1 Accuracy。

需要同时处理四个问题：

1. 错误标签产生方向相反的监督梯度；
2. 困难样本与噪声样本在训练早期都可能表现为高损失；
3. 头部类别的数量优势会进一步放大伪标签偏差；
4. 无约束微调容易破坏 CLIP 的预训练表示。

因此，方案不把“低置信度”等同于“错误标签”，也不依赖单一模型对自身训练样本作
一次性判断。整体采用“独立先验初始化、连续可信加权、谨慎标签修正、后期长尾校准”
的顺序。

## 2. 总体架构

CAPR-CLIP 包含五个相互解耦的模块：

| 模块 | 作用 | 输出 |
|---|---|---|
| 数据审计 | 发现坏图、重复图和类别分布问题 | 可复现 manifest |
| 独立可信度估计 | 区分可靠监督、困难样本和疑似噪声 | 初始可信度 `q0` |
| LoRA 鲁棒微调 | 适配细粒度领域并控制参数漂移 | 微调视觉编码器 |
| 自适应表征约束 | 对疑似噪声施加更强预训练先验 | 稳定的视觉表示 |
| 延迟长尾校准 | 在表示稳定后修正分类边界 | 最终分类头 |

模块应逐项加入并完成消融，不在第一轮实验中一次性全部启用。

## 3. 数据审计与验证划分

### 3.1 自动数据审计

- 使用 Pillow 统一转为 RGB，并允许读取可恢复的截断图像；
- 记录文件名、类别、尺寸、长宽比、文件哈希和解码状态；
- 使用文件哈希识别完全重复图，使用感知哈希识别近重复图；
- 跨类别重复样本不人工删除，标记后交由可信度模块降权；
- 保存 `manifest.csv` 和审计统计，确保同一配置可以完全复现。

### 3.2 防泄漏划分

先将重复及近重复图像组成 group，再进行按类别分层的 group split。默认使用固定的
90%/10% 训练验证划分；尾部类无法稳定划分时，采用固定三折 OOF 评估。

重要约束：原型、可信度归一化、伪标签阈值和类别统计只能由训练折计算，验证折不得
参与这些统计量的拟合。

## 4. 独立初始可信度

可信度初始化使用冻结的官方 CLIP 图像特征，不使用正在微调的候选模型，避免循环判断。
对样本 `i` 计算三个信号。

### 4.1 OOF 分类置信度

在冻结特征上训练三折 OOF 余弦分类器。每个样本的预测必须来自没有见过该样本的折：

```math
s_i^{cls}=P_{-fold(i)}(y_i\mid x_i)
```

若某类别不足以支持三折，则该类别不使用分类器置信度，由另外两个信号回退估计。

### 4.2 留一原型间隔

样本不得参与自身类别原型的计算。设 `p_{y_i}^{-i}` 为留一鲁棒原型：

```math
s_i^{proto}=cos(z_i,p_{y_i}^{-i})-\max_{c\ne y_i}cos(z_i,p_c)
```

鲁棒原型优先采用截尾均值或 medoid。留一计算避免样本先污染原型，再用该原型给自身
打高分。

### 4.3 mutual-kNN 邻域一致率

在冻结特征空间中建立 mutual-kNN 图，仅保留互为近邻的连接：

```math
s_i^{knn}=\frac{\sum_{j\in N_i}w_{ij}\mathbb{1}(y_j=y_i)}
                  {\sum_{j\in N_i}w_{ij}+\epsilon}
```

局部邻域可以覆盖同一类别中的姿态、视角等多模态结构，比单个类别均值更适合细粒度
数据。

### 4.4 信号融合

三个信号先在类别内转为百分位，再映射到 `[0,1]`。默认取可用信号的均值：

```math
q_i^0=mean(rank_c(s_i^{cls}),rank_c(s_i^{proto}),rank_c(s_i^{knn}))
```

这里使用等权作为可解释起点，不预设缺少实验依据的复杂权重。后续只允许通过固定验证
协议调整融合权重。

## 5. 模型与参数高效微调

### 5.1 骨干和分类头

- 骨干固定为 OpenAI 官方 CLIP ViT-B/32；
- 文本塔保持冻结；若官方只提供类别编号，主方案不依赖类别名称或文本提示；
- 分类头使用归一化特征和归一化权重构成的余弦分类器；
- 温度参数可训练，但需要设置合理上下限。

### 5.2 LoRA 起始配置

第一版只在视觉 Transformer 最后四层 Attention 的 Q/V 投影加入 LoRA：

- rank：8；
- alpha：16；
- dropout：0.05；
- LoRA 学习率：`1e-4`；
- 分类头学习率：`5e-4`；
- 最后四层 LayerNorm 可训练，学习率：`1e-5`。

必须通过消融比较最后四层 Q/V、全部层 Q/V 和最后四层 Q/K/V/O，不能默认扩大 rank
一定有效。

## 6. 动态可信度与监督策略

微调期间每个 epoch 使用固定弱增强单独评分。动态分数包含监督损失排名、EMA 预测一致性
和原型间隔，但冻结特征得到的 `q0` 始终保留最低占比：

```math
q_i^t=\beta q_i^0+(1-\beta)EMA(q_i^{model,t}),\quad \beta\ge 0.5
```

该设计防止当前模型完全覆盖独立先验并形成自我确认。动态可信度使用时间 EMA 和迟滞
更新，减少样本在不同状态间频繁跳变。

### 6.1 原标签监督

可信度主要作为连续权重，而不是硬删除条件：

```math
L_{sup}=\frac{\sum_i q_i L_{robust}(f(x_i),y_i)}{\sum_i q_i+\epsilon}
```

`L_robust` 首先比较 CE、GCE，确认收益后再考虑其他鲁棒损失。多个鲁棒损失不叠加使用。

### 6.2 软标签和伪标签门控

EMA 是同一学生训练轨迹的参数影子，不独立优化。它只处理当前阶段训练集的弱增强视图。

中可信样本使用原标签与教师软分布的连续混合；低可信样本只有同时满足以下条件时才接受
教师目标：

- Top-1 置信度超过验证集确定的门槛；
- Top-1 与 Top-2 预测间隔超过门槛；
- 弱增强与强增强预测一致；
- 预测类别得到冻结特征 kNN 邻域支持。

未通过门控的低可信样本不指定新类别，只施加增强一致性和特征锚定。伪标签阈值按类别
校准，并限制每类每轮接纳数量，避免伪标签向头部类别坍缩。

## 7. 自适应表征锚定

冻结官方 CLIP 对当前阶段训练图像产生参考特征 `z_i^0`。微调特征为 `z_i`，锚定损失为：

```math
L_{anchor,i}=\lambda_i(1-cos(z_i,z_i^0))
```

```math
\lambda_i=\lambda_{min}+\lambda_{uncertain}(1-q_i)
```

高可信样本获得更大的领域适配空间，疑似噪声样本受到更强的预训练先验约束。参考特征只
服务于训练，最终推理不加载第二个 CLIP 分支。

高可信样本可以额外使用类别原型约束：

```math
L_{proto}=1-cos(z_i,p_{y_i})
```

原型约束作为后续消融项，不与可信度初始化强绑定。

## 8. 总损失

```math
L=L_{sup}+\lambda_{soft}L_{soft}+\lambda_{cons}L_{cons}
  +\lambda_{proto}L_{proto}+L_{anchor}
```

- `L_sup`：可信度加权的标签监督；
- `L_soft`：通过门控后使用的 EMA 软目标；
- `L_cons`：同一图像弱、强增强之间的一致性；
- `L_proto`：高可信样本的类别原型约束；
- `L_anchor`：可信度自适应的特征保持。

辅助损失在分类头预热后逐步启用，每个损失必须有独立消融结果。

## 9. 延迟长尾校准

长尾处理与表示学习分开，避免在模型尚不可靠时放大尾部类噪声。

### 9.1 表示学习阶段

采用自然采样或温和的平方根采样，不同时叠加类别重采样、类别权重和 Balanced Softmax。

### 9.2 分类头再训练

主方案采用 cRT：冻结视觉编码器，仅使用可信权重和类别均衡采样重新训练分类头 3～5 个
epoch。备选方案为可信有效数量上的弱 logit adjustment：

```math
\tilde n_c=EMA\left(\sum_i q_i\mathbb{1}(y_i=c)\right)
```

```math
z'_c=z_c+\tau\log(max(\tilde n_c,n_{min}))
```

`cRT` 与 `logit adjustment` 先分别比较，不默认同时启用。

## 10. 分阶段训练流程

### Stage 0：数据审计

生成 manifest、重复图 group、类别统计和固定验证划分。

### Stage 1：冻结特征与可信度

缓存冻结 CLIP 特征，运行 OOF 分类器、留一原型和 mutual-kNN，得到 `q0`。

### Stage 2：分类头预热

冻结视觉编码器，仅训练余弦分类头 3～5 个 epoch。此阶段不使用伪标签。

### Stage 3：鲁棒 LoRA 微调

训练 LoRA、分类头和指定 LayerNorm。逐步启用动态可信度、EMA 软目标和自适应锚定，
建议训练 30～40 个 epoch。

### Stage 4：长尾校准

冻结表示，使用 cRT 重新学习分类边界。是否启用该阶段由验证集结果决定。

### Stage 5：全量重训

固定超参数后，从官方 CLIP 权重重新初始化。使用当前阶段全部训练数据，通过 OOF 方式重新
生成可信度并完成最终训练，不继承其他阶段的权重、原型或缓存。

## 11. 细粒度增强和输入分辨率

ViT-B/32 在 224 输入下只有 7x7 个 patch，局部纹理可能成为瓶颈。实验中应比较 224 与
288/320 输入，并对位置编码做插值。建议从保守增强开始：

- RandomResizedCrop：`scale=(0.8, 1.0)`；
- 水平翻转；
- 轻度颜色扰动；
- 默认关闭 Random Erasing 和大面积 CutMix；
- 强增强只用于一致性分支，不替代干净评分视图。

升分辨率必须作为独立变量验证，避免与可信度模块同时改变。

## 12. 推理与合规要求

最终部署时将 LoRA 增量代数折叠进同一模型的线性层，只保留一个 checkpoint。推理流程为：

1. 固定 Resize 和 CenterCrop；
2. 单个模型执行一次前向；
3. 对分类 logits 取 `argmax`；
4. 类别编号补足四位并生成 `pred_results.csv`；
5. 检查文件名、顺序、行数、重复项和缺失项。

禁止使用测试时适配、多裁剪 TTA、教师学生投票、原始模型与微调模型 logits 融合以及多个
checkpoint 平均。

## 13. 主要风险

| 风险 | 监控信号 | 应对措施 |
|---|---|---|
| 困难样本被当成噪声 | 尾类可信度过低、训练召回下降 | OOF 独立先验、连续权重、最低保留数 |
| 尾类 GMM 不稳定 | 小类分量坍缩 | 小类禁用逐类 GMM，使用稳健分位数回退 |
| 伪标签确认偏差 | 伪标签集中到少数头部类 | 多条件门控、类别限额、延迟启用 |
| 长尾过度补偿 | Macro 上升但 Top-1 明显下降 | cRT 与 logit adjustment 分开比较 |
| LoRA 适配不足 | 训练和验证均欠拟合 | 比较注入层和 rank，不直接全量解冻 |
| 预训练知识遗忘 | 冻结特征相似度持续下降 | 自适应锚定、降低视觉层学习率 |

## 14. 最小可行版本

第一版只实现以下闭环：

```text
分组验证划分
+ 冻结特征 OOF/kNN 可信度
+ LoRA
+ 连续可信加权 CE/GCE
+ 自适应特征锚定
+ 后期 cRT
```

EMA 软标签、多原型和升分辨率应在最小版本稳定后逐项加入。
