# CAPR-CLIP 技术路线 V2

> 面向噪声标签与长尾分布的细粒度图像识别鲁棒微调。
> 唯一骨干：OpenAI 官方 CLIP ViT-B/32 · 指标：Top-1 Accuracy · 阶段：初赛 → 复赛 → 半决赛。

## 0. 版本说明

本文件是 CAPR-CLIP 技术路线（`TECHNICAL_ROADMAP.md`，下称 V1）的升级版。V2 **不改变 V1 的骨架与合规边界**，仅对三个模块做升级、对若干模块做可选增强，并补齐创新点叙事。所有升级均基于 2024–2026 公开工作的佐证，改动点以 `【V2】` 标注，其余沿用 V1。

### V1 → V2 变更摘要

| 模块 | V1 | V2 | 优先级 |
|---|---|---|---|
| 初始可信度 q0 | 三信号类别内百分位等权融合 | 加 GMM 双分量信号 + 尾类保护 | **P0** |
| 长尾校准 | cRT（可信权重 + 均衡采样） | cRT 升级：label over-smoothing + 可选 BS-cRT | **P0** |
| 动态可信度 | 连续权重 | 加尾类 floor + class-wise 接纳配额 | **P0** |
| 可信度信号源 | OOF + 留一原型 + mutual-kNN | 可选第四信号：文本原型（仅类别名可用时） | P1 |
| 分辨率 | 224，主线稳定后再搜 | 提前与主线并行验证 288/320 | P1 |
| 微调方式 | LoRA | 可选 CoOp 备选（仅类别名可用时） | P2 |
| 创新叙事 | 独立可信度 + 锚定 | 一致性模块以 on-policy self-distillation 叙事包装 | P1 |

## 1. 问题定义

任务：训练标签含噪、类别间差异细微、部分阶段长尾分布，用固定骨干 CLIP ViT-B/32 做单标签分类，指标 Top-1 Accuracy。

四个待解问题：

1. 错误标签产生方向相反的监督梯度；
2. 困难样本与噪声样本在训练早期都表现为高损失；
3. 头部类别的数量优势会进一步放大伪标签偏差；
4. 无约束微调破坏 CLIP 预训练表示。

V2 显式补第五个问题（V1 隐含但未点名）：

5. **确认偏差（endogenous confirmation bias）**：用正在微调的模型或 CLIP 零样本预测对自身训练样本做判断，会形成循环自我强化。这是噪声标签学习里 80% 翻车的根源，V1 的「独立可信度」正是为此设计，V2 继续强化。

五个解耦模块，顺序不变：

| 模块 | 作用 | 输出 | V2 变化 |

## 3. 数据审计与验证划分（沿用 V1）

- Pillow 统一 RGB，允许读取可恢复截断图；
- 记录文件名、类别、尺寸、长宽比、文件哈希、解码状态；
- 文件哈希识别完全重复，感知哈希识别近重复；
- 跨类别重复样本不人工删除，标记后交可信度模块降权；
- 保存 `manifest.csv` 与审计统计，确保可复现。

**防泄漏划分（不变）**：重复/近重复图组成 group 后做按类分层的 group split；默认 90/10，尾类不稳时固定三折 OOF。原型、可信度归一化、伪标签阈值、类别统计只能由训练折计算。

## 4. 独立初始可信度（V2 重点升级）

可信度初始化只用冻结官方 CLIP 特征，不用正在微调的候选模型，避免循环判断。

### 4.1 三信号（沿用 V1）

- **OOF 分类置信度**：冻结特征上三折 OOF 余弦分类器，`s_i^cls = P_{-fold(i)}(y_i | x_i)`。
- **留一原型间隔**：`s_i^proto = cos(z_i, p_{y_i}^{-i}) − max_{c≠y_i} cos(z_i, p_c)`，鲁棒原型用截尾均值或 medoid。
- **mutual-kNN 邻域一致率**：`s_i^knn = Σ_{j∈N_i} w_ij·1(y_j=y_i) / (Σ_{j∈N_i} w_ij + ε)`。

### 4.2 【V2-P0】新增第四信号：GMM 双分量后验

用 OOF 分类器的 CE loss `ℓ_i` 拟合双分量高斯混合模型：

```math
p(ℓ) = π_c · N(ℓ; μ_c, σ_c) + π_n · N(ℓ; μ_n, σ_n),\quad μ_c < μ_n
```

干净样本 loss 小、噪声样本 loss 大。样本 i 属于干净分量的后验作为第四信号：

```math
s_i^{gmm} = \frac{π_c N(ℓ_i; μ_c, σ_c)}{p(ℓ_i)}
```

**动机**：V1 的「类别内百分位」偏启发式；GMM 是 small-loss 技巧的现代正规化版本，且在细粒度数据集上验证过（[NeaR](https://www.arxiv.org/pdf/2505.01064)、[PoND](https://openreview.net/attachment?id=MpuMza23aL&name=pdf)）。**验证方式**：用 EXPERIMENT_PLAN 第二阶段「人工注入 10/20/40% 噪声的诊断实验」对标 GMM 与百分位的噪声检出率。

### 4.3 【V2-P1】可选第五信号：文本原型相似度（仅类别名可用）

若官方提供可靠类别名，加 `s_i^text = cos(z_i, t_{y_i})`（文本塔编码类别名）。图像原型比文本原型更不易被错误伪标签污染（[DPA](https://openaccess.thecvf.com//content/WACV2025/papers/Ali_DPA_Dual_Prototypes_Alignment_for_Unsupervised_Adaptation_of_Vision-Language_Models_WACV_2025_paper.pdf)，WACV 2025），故文本信号只作辅助。**主方案不依赖类别名**。

### 4.4 信号融合

```math
q_i^0 = \text{mean}\big(rank_c(s_i^{cls}), rank_c(s_i^{proto}), rank_c(s_i^{knn}), [rank_c(s_i^{gmm})]\big)
```

默认等权，只允许通过固定验证协议调融合权重。

### 4.5 【V2-P0】尾类保护

CARE（[arXiv 2605.23254](https://arxiv.org/pdf/2605.23254)）的核心结论：**单纯降低整体噪声率不够，必须 class-aware，重点是纠正尾类标签**；尾类干净样本最容易被误判成噪声。落地两种机制，作为独立消融项：

- **尾类 q0 floor**：尾类样本的 `q0` 设更高下限（建议 0.7，头类保持 0.5），直接阻止尾类被整体压成低可信；
- **class-wise Top-K 保留**：每个类按 `q0` 保留 top-K 比例样本，尾类保留比例高于头类（头类大 K、尾类小 K，借鉴 [CARE](https://arxiv.org/pdf/2605.23254) 的 class-wise voting）。

> 尾类的划分沿用 EXPERIMENT_PLAN：按当前阶段训练集类别样本量分位数固定划分头/中/尾，并写入实验产物，禁止跨实验改动。

## 5. 模型与参数高效微调

### 5.1 骨干和分类头（沿用 V1）

- 骨干固定 OpenAI 官方 CLIP ViT-B/32；文本塔冻结；主方案不依赖类别名或文本提示；
- 余弦分类器（归一化特征 × 归一化权重），温度可训练但有上下限。

### 5.2 LoRA 起始配置（沿用 V1）

末四层 Attention Q/V 投影注入：rank 8、alpha 16、dropout 0.05；LoRA lr `1e-4`、分类头 lr `5e-4`、末四层 LayerNorm lr `1e-5`。消融比较「末四层 Q/V / 全部层 Q/V / 末四层 Q/K/V/O」，不默认扩大 rank。

### 5.3 【V2-P2】可选 CoOp 备选（仅类别名可用）

若提供类别名，prompt tuning 在 ViT-B/32 上收益最大（[ProAPO](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Qu_ProAPO_Progressively_Automatic_CVPR_2025_supplemental.pdf)，CVPR 2025，细粒度平均 +3.4%，ViT-B/32 优于 ViT-B/16/L/14），可作为 LoRA 的备选消融项。**主方案仍是 LoRA**，CoOp 仅在类别名可靠且 LoRA 欠拟合时启用。

## 6. 动态可信度与监督策略

动态分数 `q_i^t = β q_i^0 + (1−β) EMA(q_i^{model,t})`，`β ≥ 0.5`，冻结特征先验始终占主导，防止自我确认。动态分数用时间 EMA 与迟滞更新。

### 6.1 原标签监督（沿用 V1）

```math
L_{sup} = \frac{\sum_i q_i L_{robust}(f(x_i), y_i)}{\sum_i q_i + \epsilon}
```

`L_robust` 先比 CE 与 GCE，不同时叠加多个鲁棒损失。

### 6.2 软标签与伪标签门控（沿用 V1 + V2 配额升级）

EMA 是同一条训练轨迹的参数影子，不独立优化，只处理当前阶段训练集弱增强视图。中可信样本用原标签与教师软分布连续混合；低可信样本须同时满足四条件才接受教师目标：Top-1 置信度过门槛、Top-1/Top-2 间隔过门槛、弱强增强预测一致、预测类别获冻结特征 kNN 邻域支持。

【V2-P0】伪标签接纳从「per-class 固定配额」升级为 **class-wise Top-K**（头类小 K、尾类大 K，防止伪标签向头部坍缩，与 4.5 尾类保护同源）。

---

## 7. 自适应表征锚定（沿用 V1）

```math
L_{anchor,i} = λ_i (1 − cos(z_i, z_i^0)),\quad λ_i = λ_{min} + λ_{uncertain}(1 − q_i)
```

高可信样本获得更大领域适配空间，疑似噪声样本受更强预训练先验约束。参考特征只用于训练，推理不加载第二个 CLIP 分支。高可信样本可加类别原型约束 `L_proto = 1 − cos(z_i, p_{y_i})`（消融项）。

---

## 8. 总损失（沿用 V1）

```math
L = L_{sup} + λ_{soft}L_{soft} + λ_{cons}L_{cons} + λ_{proto}L_{proto} + L_{anchor}
```

辅助损失在分类头预热后逐步启用，每项独立消融。

### 8.1 【V2-P1】一致性模块的创新叙事（不引入新方法，只换叙事）

`L_cons`（弱/强增强一致性）+ EMA 一致性，本质上就是「clean 视图的模型预测监督 corrupted 视图的输出」。这正是 on-policy self-distillation 的判别式形态（[NOPD](https://arxiv.org/abs/2607.23125) 的 token 级思想在分类层的退化；[S²VOPD](https://arxivlens.com/paperview/details/self-supervised-visual-on-policy-distillation-3359-3b49c53e) 的「EMA teacher 看 clean 图、student 看增强图」与本模块几乎同构）。

**结论**：技术报告用「无外部教师的 on-policy self-distillation 抗噪一致性」来表述该模块，即可补齐创新点，而**不引入 NOPD 的 token 级自蒸馏框架**（其面向生成式 MLLM、reverse KL、冷启动与自我强化错误风险高，与判别式分类场景不适配）。

## 9. 延迟长尾校准（V2 重点升级）

长尾处理与表示学习分离，避免模型尚不可靠时放大尾类噪声。

### 9.1 表示学习阶段（沿用 V1）

自然采样或温和平方根采样，不同时叠加重采样、类别权重、Balanced Softmax。

### 9.2 【V2-P0】分类头再训练升级

主方案仍为 cRT（冻结视觉编码器，仅重训分类头 3–5 epoch），但加两处升级：

- **Label Over-Smoothing**（[ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/42a452cbafa9dd64e9ba4aa95cc1ef21-Abstract-Conference.html)）：cRT 阶段软化 one-hot 标签，不需要类别先验知识，零成本。形式为

  ```math
  \tilde y_i = (1-α)·y_i + α/K
  ```

  `α` 为平滑系数，`K` 为当前阶段类别数。该文发现 logits magnitude 均衡后降低其总体值可减少训练扰动。

- **可选 BS-cRT**（[arXiv 2607.09832](https://browse-export.arxiv.org/pdf/2607.09832)）：分类头重训改用 Balanced Softmax + class-balanced episodic batches，推理用 raw cosine logits。尾类大幅提升，但**该文自报 Top-1 与 Few-shot 存在 trade-off**，且其 CBRM 边界探针实验失败（最难负样本锚到头部类，反而降 4 点）。

**关键警告**：赛题主指标是 Top-1，Balanced Softmax 会牺牲头部类换尾类，可能伤 Top-1。因此 BS-cRT 必须作为独立消融项（对应 EXPERIMENT_PLAN 的 L1/L2/L3 里新增一项），**不得默认启用**；label over-smoothing 可与 cRT 直接叠加，风险低。

### 9.3 备选（沿用 V1）

可信有效数量上的弱 logit adjustment：`\tilde n_c = EMA(Σ_i q_i 1(y_i=c))`，`z'_c = z_c + τ log(max(\tilde n_c, n_min))`。cRT、BS-cRT、logit adjustment 先分别比较，不默认组合。

## 10. 分阶段训练流程（沿用 V1，微调）

Stage 0 数据审计 → Stage 1 冻结特征与可信度（V2：含 GMM 与尾类保护）→ Stage 2 分类头预热 → Stage 3 鲁棒 LoRA 微调（30–40 epoch）→ Stage 4 长尾校准（V2：cRT + label over-smoothing，可选 BS-cRT）→ Stage 5 全量重训（从官方权重重新初始化，OOF 重新生成可信度，不继承其他阶段产物）。

---

## 11. 细粒度增强与输入分辨率（V2 提升优先级）

ViT-B/32 在 224 输入下仅 7×7 patch，局部纹理是瓶颈。V2 把分辨率实验**从「主线稳定后」提前为与主线并行的独立变量**：

- 输入 224 与 288/320 对比，位置编码插值；
- 保守增强起步：RandomResizedCrop `scale=(0.8, 1.0)`、水平翻转、轻度颜色扰动；默认关 Random Erasing 与大面积 CutMix；
- 强增强只用于一致性分支，不替代干净评分视图。

**佐证**：细粒度场景下升分辨率与 prompt 优化收益显著（[CLIPer](https://openaccess.thecvf.com/content/ICCV2025/papers/Sun_CLIPer_Hierarchically_Improving_Spatial_Representation_of_CLIP_for_Open-Vocabulary_Semantic_ICCV_2025_paper.pdf) 用 336px；[ProAPO](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Qu_ProAPO_Progressively_Automatic_CVPR_2025_supplemental.pdf) 细粒度 +3.4%）。分辨率与可信度模块正交，可并行验证，不必等主线收敛。升分辨率必须作为独立变量，避免与可信度模块同时改。

---

## 12. 推理与合规要求（沿用 V1，不变）

LoRA 增量折叠进同一模型线性层，只保留一个 checkpoint。推理：固定 Resize + CenterCrop → 单模型单次前向 → argmax → 类别编号四位补零 → `pred_results.csv` → 校验文件名/顺序/行数/重复/缺失。

禁止：测试时适配、多裁剪 TTA、教师学生投票、原模型与微调模型 logits 融合、多 checkpoint 平均。**V2 所有新增模块均不改变此边界**（GMM、label over-smoothing、BS-cRT 都在训练期/校准期，推理仍单模型单裁剪单前向）。

## 13. 主要风险（V2 更新）

| 风险 | 监控信号 | 应对措施 |
|---|---|---|
| 困难样本被当成噪声 | 尾类可信度过低、训练召回下降 | OOF 独立先验、连续权重、**V2 尾类 floor / class-wise Top-K** |
| 尾类被整体判低可信 | 尾类 `q0` 分布异常集中 | 尾类保护消融（4.5） |
| GMM 双分量退化 | 单分量坍缩、检出率低于分位数 | 小类禁用 GMM，回退分位数 |
| 伪标签确认偏差 | 伪标签集中到头部类 | 多条件门控、class-wise 配额、延迟启用 |
| BS-cRT 伤 Top-1 | Macro 升但 Top-1 降 | 作为独立消融，不默认启用；保留纯 cRT |
| 长尾过度补偿 | Macro 升、Top-1 明显降 | cRT / BS-cRT / logit adjustment 分开比较 |
| LoRA 适配不足 | 训练验证均欠拟合 | 比较注入层与 rank；类别名可用时试 CoOp |
| 预训练知识遗忘 | 冻结特征相似度持续下降 | 自适应锚定、降低视觉层学习率 |
| 分辨率升带来算力/显存压力 | 训练吞吐、显存 | 记录吞吐与耗时，按 8GB 复现上限决策 |

## 14. 最小可行版本（V2 更新）

第一版闭环：

```text
分组验证划分
+ 冻结特征 OOF/kNN 可信度（含 GMM 信号 + 尾类保护）
+ LoRA
+ 连续可信加权 CE/GCE
+ 自适应特征锚定
+ 后期 cRT + label over-smoothing
```

EMA 软标签、文本原型、CoOp、BS-cRT、升分辨率在 MVP 稳定后逐项加入。

**优先执行路径（时间受限时）**：`B0 → B1 → T4(+GMM) → R1 → R2 → L1(+over-smoothing)`，与 EXPERIMENT_PLAN 一致，仅在其上插入 V2 的 GMM 与 over-smoothing。
