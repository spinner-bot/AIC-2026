# CAPR-CLIP V3 方案包

## 目录说明

本目录用于保留 V2 的输入材料、V2 的批判性审查过程以及 V3 的最终方案，形成可追溯的方案演进链：

```text
V1 对照副本
V2 原始技术路线
V2 原始实验计划 / 配置 / README
        ↓
V2 批判性分析
        ↓
V3 技术路线
```

## 文件说明

- `V1_技术路线_对照副本.md`：V2 的直接上游方案；
- `V2_技术路线_原始副本.md`：团队成员提交的原始 V2；
- `V2_实验计划_原始副本.md`：V2 配套实验计划；
- `V2_README_原始副本.md`：V2 方案说明；
- `V2_config_原始副本.yaml`：V2 配置草案；
- `V2_批判性分析.md`：对 V2 的结构化审查、问题定位和修改依据；
- `V3_技术路线.md`：基于审查结果形成的升级方案。

## V3 的基本立场

V3 不追求堆叠更多模块，而是优先修正 V2 中会影响真实成绩的结构性风险：

1. 将“独立可信度”改造成有样本支持度、信号可靠性和尾类保护的可信度系统；
2. 将 GMM 从默认升级项改成受条件约束的诊断信号；
3. 将尾类保护从固定 floor 改成最小可信质量与自适应配额；
4. 延迟并收紧教师伪标签，优先使用软一致性而不是激进纠错；
5. 将 cRT、Balanced Softmax 和 logit adjustment 拆成互斥实验分支；
6. 将“创新叙事”建立在可验证机制上，而不是仅改变术语。

V3 的第一目标是稳定跑通和提升线上 Top-1，第二目标才是方法创新和答辩表达。
