# CAPR-CLIP 技术路线 V3

> Class-Aware Prototype and Reliability-calibrated Robust CLIP  
> 任务：含噪标签、细粒度、长尾图像分类  
> 骨干：OpenAI 官方 CLIP ViT-B/32  
> 推理：单模型、单裁剪、单次前向

## 1. V3 总体结论

V3 不把更多模块简单叠加到 V2，而是将方案重构为三个相对解耦的层次：

1. **可靠度层**：仅用训练数据和冻结 CLIP 特征建立样本可信度，不直接硬删除；
2. **表示适配层**：使用 LoRA/Adapter 进行受控微调，并通过冻结特征锚定抑制灾难性遗忘；
3. **分类校准层**：在视觉表示稳定后，单独比较 cRT、弱 logit adjustment 和 Balanced Softmax。

核心主线为：

```text
数据审计与 group split
    ↓
冻结 CLIP 特征缓存
    ↓
OOF / 鲁棒原型 / mutual-kNN
    ↓
可靠度融合与尾类最小质量保护
    ↓
分类头预热
    ↓
可信度加权 LoRA + 自适应特征锚定
    ↓
延迟 cRT 分类器校准
    ↓
单模型推理
```

EMA 一致性、GMM、伪标签、文本原型、CoOp 和高分辨率均作为有条件的独立插件，不进入第一版默认主线。

## 2. V3 相对 V2 的主要修订

| 模块 | V2 做法 | V3 修订 |
|---|---|---|
| GMM | 作为 P0 新增信号 | 仅在分离度和样本量达标时启用，失败回退 |
| q0 融合 | 类内百分位等权平均 | 加入信号可靠性、冲突惩罚和样本支持度 |
| 尾类保护 | 固定 floor、Top-K 规则易歧义 | 最小可信质量 + 自适应配额，不固定 0.7 |
| 动态可信度 | EMA 模型分数持续参与 | 先冻结 q0，后期限制偏移并检测冲突 |
| 伪标签 | 多条件门控后使用 | 延迟启用，优先软一致性，严格控制覆盖率 |
| cRT / BS-cRT | 多个方向并列 | 互斥分支，以 Full-val Top-1 作为主选择指标 |
| 创新表述 | on-policy self-distillation 叙事 | 诚实表述为冻结先验约束下的噪声感知一致性 |
| 资源策略 | 复杂模块较早并行 | 先跑 MVP，再进行单变量扩展 |

## 3. 数据审计与划分

### 3.1 Manifest

每张图片记录：路径、原始类别、内部类别索引、尺寸、长宽比、Pillow 解码状态、文件哈希和感知哈希。异常图像不人工修改；能够读取的截断图保留，无法读取的图像进入异常清单。

### 3.2 防泄漏 group split

完全重复和近重复图片组成同一 group，再进行按类别分层划分。默认使用固定 90/10 训练/验证划分；小类别不足以稳定划分时使用固定三折 OOF。

所有原型、可信度归一化、GMM 参数、类别统计和伪标签阈值只能从训练折计算。验证折只能用于评估，不能参与可信度拟合或调参统计。

### 3.3 头中尾划分

按当前阶段训练集的类别样本量分位数固定划分头部、中部和尾部类别，并把划分结果写入实验产物。不同实验不得重新定义头中尾边界。

## 4. 冻结特征与可靠度系统

### 4.1 冻结特征

使用官方 CLIP ViT-B/32 图像塔提取 L2 归一化特征 (z_i^0)。这些特征只用于训练期可靠度、原型和锚定，不作为额外推理分支，因此不会构成模型集成。

### 4.2 三个基础信号

#### OOF 分类信号

在冻结特征上训练余弦分类器，每个样本的预测来自未见过该样本的折：

\[
s_i^{cls}=P_{-fold(i)}(y_i|x_i)
\]

该信号仍可能继承标签噪声，因此只作为带偏差的判别证据。

#### 留一鲁棒原型信号

对标签类别构建不包含样本自身的鲁棒原型：

\[
s_i^{proto}=cos(z_i^0,p_{y_i}^{-i})-max_{c\ne y_i}cos(z_i^0,p_c)
\]

大类别使用截尾均值或 medoid；小类别使用向全局原型收缩的原型：

\[
p_c=\rho_c p_c^{local}+(1-\rho_c)p^{global}
\]

其中 ρ 随有效样本量增加而增加。

#### mutual-kNN 局部信号

在训练折冻结特征空间中建立 mutual-kNN 图。只有 (j) 是 (i) 的 top-k 近邻且 (i) 也是 (j) 的 top-k 近邻时，才建立连接。使用非负相似度作为边权：

\[
w_{ij}=max(cos(z_i^0,z_j^0),0)
\]

邻域一致率为：

\[
s_i^{knn}=\frac{\sum_{j\in N_i}w_{ij}\mathbf{1}(y_j=y_i)}{\sum_{j\in N_i}w_{ij}+\epsilon}
\]

推荐比较 (k=20) 和 (k=50)，并报告跨类边比例、邻域类别熵和尾类邻域覆盖率。

### 4.3 条件 GMM 信号

先用 OOF 分类器计算样本损失 ℓ_i，再尝试拟合干净/噪声双分量 GMM。启用条件为：

- 分量有效样本量达到阈值；
- 两分量均有稳定方差；
- 多次初始化结果相近；
- 分离度优于简单类内百分位基线。

满足条件时使用干净分量后验 (s_i^{gmm})，否则回退到类内百分位。GMM 后验只能作为辅助信号，不允许单独删除样本。

### 4.4 可靠度融合

各信号在类别内转换为稳健秩分数 ~tilde{s}_{im}。同时计算信号冲突度：

\[
d_i=Var(\tilde{s}_{i,cls},\tilde{s}_{i,proto},\tilde{s}_{i,knn},[\tilde{s}_{i,gmm}])
\]

初始可靠度定义为：

\[
q_i^0=clip\left(\sum_m a_m\tilde{s}_{im}-\lambda_d d_i, q_{min},1\right)\cdot g(n_{y_i})
\]

其中 (a_m) 为固定或基于人工注入噪声诊断集确定的权重，(g(n_{y_i})) 为类别支持度修正，不直接把尾类全部抬高。

推荐初始实现：基础三信号等权，GMM 只在有效时加入；信号高度相关时降低重复信号权重；冲突明显时降低 q0。

### 4.5 尾类保护

不使用固定 `q0=0.7` floor。V3 采用两层保护：

1. 每类保留一个最小可信质量：保证每类至少有足够的有效监督，但不保证所有尾类样本高权重；
2. 伪标签按类别设置最大接纳配额，配额与类别有效数量、可信度分布和当前头中尾比例相关。

需要明确区分：保留数量、保留比例、总可信权重和伪标签配额，禁止用同一个 K 同时表示它们。

## 5. 模型与损失

### 5.1 参数高效微调

主线使用视觉 LoRA：最后四层 Attention 的 Q/V 投影，rank=8、alpha=16、dropout=0.05。分类头和最后四层 LayerNorm 可训练。全部层 Q/V、Q/K/V/O 和不同 rank 只作为容量消融。

文本塔保持冻结。若没有可靠类别名称，完全不启用文本原型和 CoOp。

### 5.2 阶段化损失

监督项使用连续可靠度权重：

\[
L_{sup}=\frac{\sum_i w_iL_{robust}(f(x_i),y_i)}{\sum_iw_i+\epsilon}
\]

第一轮只比较 CE 与 GCE，不同时叠加多个鲁棒损失。

冻结特征锚定为：

\[
L_{anchor,i}=\lambda_i(1-cos(z_i,z_i^0))
\]

\[
\lambda_i=\lambda_{min}+\lambda_{uncertain}(1-q_i)
\]

低可信样本受到更强先验保护，高可信样本获得更大适配空间。

总损失初始为：

\[
L=L_{sup}+L_{anchor}
\]

只有在主线稳定后，才逐项加入一致性、原型约束和软标签损失。

## 6. 动态可信度与一致性

### 6.1 q0 冻结期

分类头预热和 LoRA 微调的前若干 epoch 固定 (q_i^0)，不使用当前模型反向修改样本权重。此阶段用于观察表示是否稳定、损失是否下降和类别是否坍缩。

### 6.2 受限动态更新

稳定后允许模型证据有限地修正 q0：

\[
q_i^t=clip(q_i^0+\eta\Delta_i^t,q_i^0-\delta,q_i^0+\delta)
\]

其中 Δ 来自类内校准后的 EMA 预测、增强一致性和原型间隔，δ 控制模型对独立先验的最大偏移。若模型证据与冻结特征证据严重冲突，则降低 q 而不是直接取平均。

### 6.3 EMA 一致性

EMA 只作为训练期参数平滑器，不作为第二个推理模型。弱增强图像交给 EMA，强增强图像交给学生，先使用 KL 软一致性，不立即生成硬伪标签。

### 6.4 伪标签门控

伪标签默认关闭。启用时必须同时满足：高置信度、足够 Top-1/Top-2 间隔、弱强增强一致、冻结特征邻域支持和类别配额未满。每轮记录伪标签覆盖率、类别熵、与 q0 的冲突率和跨轮稳定率。

若覆盖率过低，保持软一致性，不为了提高覆盖率而降低门槛；若类别熵明显下降，立即关闭伪标签分支。

## 7. 延迟长尾校准

表示学习阶段使用自然采样或温和平方根采样，不同时叠加重采样、类别权重和 Balanced Softmax。

表示稳定后冻结视觉编码器，分别比较：

1. 可信权重 cRT；
2. 弱 logit adjustment；
3. Balanced Softmax cRT；
4. label over-smoothing cRT。

这些方案保持互斥。主选择指标是 Full-val Top-1；Macro、Head/Middle/Tail Accuracy 用于解释收益来源，不能用尾类提升替代总体准确率。

## 8. 分阶段执行方案

### Stage 0：审计与分组划分

生成 manifest、重复 group、固定验证集和数据哈希。

### Stage 1：冻结特征缓存

提取 CLIP 特征，使用 FAISS 或分块近邻搜索，禁止构造 100k 级全量两两矩阵。

### Stage 2：q0 诊断

生成 OOF、鲁棒原型、mutual-kNN 和可选 GMM 信号；检查信号相关性、尾类分布、GMM 退化和注入噪声检出率。

### Stage 3：MVP 微调

冻结 q0，运行分类头预热，再训练 LoRA + 可靠度加权 CE/GCE + 自适应锚定。

### Stage 4：可选增强

依次加入 EMA 一致性、原型约束、受限动态可信度和严格门控伪标签。每次只改变一个主要变量。

### Stage 5：分类器校准

执行 cRT、logit adjustment、BS-cRT 和 label over-smoothing 的独立实验。

### Stage 6：容量与分辨率

在主线固定后比较 224、288、320 和 LoRA 注入位置。每次记录显存、吞吐、验证准确率和推理耗时。

### Stage 7：阶段重训

确定配置后，从官方 CLIP 权重重新初始化，使用当前阶段允许的全部训练数据重新生成 OOF、原型和可靠度，再完成最终训练。不同赛事阶段不继承训练数据、原型或可信度缓存。

## 9. 实验门槛

模块进入主方案必须同时满足：

1. 固定 Full-val Top-1 有稳定提升；
2. 提升超过随机种子波动，或至少在多个种子上方向一致；
3. 没有不可接受的 Head Accuracy 损失；
4. 训练不依赖人工样本名单或测试集统计；
5. 资源消耗满足最终复现要求；
6. 移除模块后消融结果出现一致退化。

推荐最小执行路径：

```text
B0 冻结 CLIP
→ B1 LoRA
→ R1 可靠度加权 CE/GCE
→ R2 自适应锚定
→ L1 cRT
```

推荐扩展路径：

```text
R2 → EMA 一致性 → 受限动态可信度 → 严格伪标签
   → GMM 条件信号 → 尾类配额 → 分辨率搜索
```

## 10. 监控指标与预警

| 检查项 | 正常现象 | 预警与处理 |
|---|---|---|
| q0 分布 | 类别间有差异但不极端 | 尾类整体低于头类时检查原型和 GMM |
| 信号相关性 | 各信号有互补性 | 高相关时减少重复计权 |
| GMM | 双分量稳定 | 分量坍缩时回退百分位 |
| kNN 图 | 邻域类别有局部集中 | 跨类边异常增多时降低 k 或关闭该信号 |
| 特征漂移 | 适度下降后稳定 | 持续下降时减小 LoRA 学习率或增强锚定 |
| 伪标签熵 | 与真实类别规模相近 | 熵快速下降时关闭伪标签 |
| Tail Accuracy | 不持续恶化 | 重新检查尾类保护和 cRT |
| Full-val Top-1 | 稳定提升 | 只升 Macro 不升 Top-1 时不进入主线 |

## 11. 创新点的准确表述

V3 建议将创新表述为：

> 面向含噪细粒度长尾数据，构建一种冻结视觉先验约束下的类别感知可靠度校准参数高效微调方法。方法从 OOF 判别证据、鲁棒类别原型和局部互惠邻域三个层次估计样本可靠度，并通过信号冲突惩罚、类别支持度修正和尾类最小可信质量保护降低错误标签筛选偏差；随后利用可靠度加权 LoRA 与自适应先验锚定进行稳健表示适配，最后通过延迟分类器重训完成长尾校准。

这比单纯将 EMA 一致性命名为 on-policy self-distillation 更稳妥，因为每个创新点都有可实现模块和独立消融。

## 12. 可行性结论

V3 在 A100 集群或相对充足的 AutoDL 资源上可执行。最小版本只需要冻结特征缓存、FAISS 近邻、余弦分类头、LoRA、可靠度加权损失和 cRT；EMA、GMM、伪标签及高分辨率均可延后。因此即使算力或数据到位时间不稳定，也能先完成一个可提交的稳健基线，再逐步增加复杂度。

最需要提前准备的不是更复杂的模型，而是：数据审计脚本、group split、特征缓存格式、OOF 生成器、可靠度诊断报告、单变量实验模板和自动回退机制。
