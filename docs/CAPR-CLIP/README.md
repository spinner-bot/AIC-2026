# CAPR-CLIP

面向噪声标签与长尾分布的细粒度图像识别鲁棒微调技术路线。

CAPR-CLIP（Class-Aware Prototype-guided Robust CLIP）以 OpenAI 官方
CLIP ViT-B/32 为唯一骨干，通过独立可信度估计、参数高效微调、自适应表征约束
和延迟长尾校准，降低错误标签对训练的干扰，同时保留预训练模型的通用视觉先验。

> 当前状态：技术设计阶段。本文档描述计划实现和验证的方案，不代表相关模块已经完成。

## 设计目标

- 在错误标注、弱相关样本和困难样本共存时保持稳定训练；
- 防止模型将困难样本简单误判为噪声；
- 缓解复赛、半决赛中的头部类别偏置；
- 全流程自动运行，不依赖人工清洗名单；
- 最终使用一个 checkpoint、一次确定性预处理和一次模型前向完成推理。

## 核心路径

```text
当前阶段官方训练集
        |
        v
重复图分组、固定训练/验证划分
        |
        v
冻结 CLIP 特征 + OOF 分类器 + 留一原型 + mutual-kNN
        |
        v
独立初始可信度 q0（连续权重，不直接硬删除）
        |
        v
分类头预热 -> LoRA 鲁棒微调 -> 严格门控的软标签学习
        |
        v
自适应特征锚定 -> 后期 cRT 长尾校准
        |
        v
单模型、单裁剪、单次前向 -> pred_results.csv
```

## 方案边界

1. 唯一外部初始化为 OpenAI 官方公开的 CLIP ViT-B/32 权重。
2. 每个赛事阶段仅使用当前阶段官方训练数据，并从官方权重重新训练。
3. 测试集不参与训练、聚类、伪标签、归一化统计、阈值选择或模型选择。
4. EMA 仅作为训练期参数影子生成软目标，不构成独立模型或推理分支。
5. 不使用多模型投票、checkpoint averaging、TTA 或测试时适配。
6. 所有样本权重、伪标签和筛选结果都由代码自动生成并记录。
