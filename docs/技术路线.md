# 算法4 技术路线参考

> 面向噪声标签数据的细粒度图像识别鲁棒微调
> 骨干：CLIP ViT-B/32（强制） · 指标：Top-1 Accuracy · 阶段：初赛 → 复赛 → 半决赛

---

## 一、赛题画像（先对齐硬约束）

| 维度 | 内容 |
|---|---|
| 任务 | 自然动植物**细粒度**图像分类（单标签） |
| 骨干 | **CLIP ViT-B/32**，仅限 OpenAI 官方预训练权重（`openai/clip` 或 HF `transformers` 对应版本） |
| 指标 | Top-1 Accuracy；线上综合分 = 复赛 40% + 半决赛 60% |
| 数据 | 初赛 500 类 / 103218 训练；复赛 750 类 / 148695（**长尾**）；半决赛 500 类 / 90197（**长尾**） |
| 噪声 | 训练集标签含噪（错误标注 / 弱相关 / 难样本），测试集为人工精标 |

**硬约束（踩线直接无效）**：
1. 不得替换骨干、不得用其他视觉基础模型 / 商业 API。
2. **禁止多模型集成**——最终必须是单一模型或单一推理流程。
3. **禁止引入任何外部数据**——每个阶段只能用官方当前阶段数据集，且测试集不得参与训练。
4. **训练全流程（含噪声筛选）必须由提交代码自动复现**——人工清洗不能作为必要前置环节。

## 二、核心矛盾与解题框架

**核心矛盾**：含噪标签下直接全参数微调 → ① 对错误标签过拟合 → ② 破坏 CLIP 预训练先验（灾难性遗忘）→ ③ 长尾阶段偏向头部类。

**解题框架**：**「数据层」×「模型层」双管齐下**，且全程轻量化（不放开全参数微调）：

```
                    ┌─────────────────────────────────────┐
  含噪训练集 ──────►│ 数据层：滤噪 / 伪标签 / 重加权 / 课程 │──────► 干净&加权样本
                    └─────────────────────────────────────┘              │
                    ┌─────────────────────────────────────┐              ▼
                    │ 模型层：PEFT(CoOp/LoRA) + 鲁棒损失   │◄─────  CLIP ViT-B/32（冻结主权重）
                    │          + 表征约束（防遗忘）        │
                    └─────────────────────────────────────┘
                                       │
                                       ▼
                          单一模型推理 → pred_results.csv
```

## 三、技术路线总览（四层递进）

| 层 | 目标 | 关键手段 |
|---|---|---|
| L0 基线 | 跑通全流程 | Linear Probe / 全参数微调作参照 |
| L1 数据层 | 削弱噪声干扰 | 样本选择、伪标签、置信度建模、课程学习 |
| L2 模型层 | 安全微调 | CoOp / LoRA / Adapter、鲁棒损失、OPSD 自蒸馏、表征约束 |
| L3 稳定性 | 长尾 + 泛化 | 类别重加权、Focal、WiSE-FT 权重插值 |

## 四、各模块具体方案

### 4.1 Baseline（第一步，先交上卷）

- **Linear Probe**：冻结 ViT-B/32 视觉塔，只训一个分类头。跑通数据加载 / 训练 / 推理 / 生成 `pred_results.csv`。
- **全参数微调**：作为上界参照，但只用来对标，不作为提交方案（赛题明确提示「不宜直接全参数微调」）。
- 目的：验证 pipeline 正确性 + 拿到官方基线对照分。

### 4.2 噪声标签处理（L1，核心创新空间）

噪声标签学习的经典打法，按「是否引入额外网络」分两类：

**单模型路线（更安全、易复现，优先）**
- **Small-loss 技巧**：噪声样本早期 loss 大、干净样本 loss 小；用 loss 阈值 / 动态阈值筛选干净样本。
- **置信度建模**：用模型对样本的预测置信度做软加权，低置信样本降权而非直接丢弃。
- **伪标签纠正**：用 CLIP 零样本或模型自身高置信预测给疑似噪声样本重新打标签（self-training）。
- **课程学习**：先学「易/干净」样本，再逐步引入「难/噪声」样本。

**双网络路线（效果更强，但要注意「禁集成」边界）**
- **Co-teaching / JoCoR / DivideMix**：两个网络互相选择干净样本。⚠️ 最终提交仍是单一模型，双网络仅用于**训练阶段选样**，推理只用其中一个——需在技术报告里写清，避免被判为集成。

**CLIP 特有优势**：利用「文本-图像对齐」先验做噪声判断（见 §4.6 与 §5 的 TrustCLIP / JoAPR 思路），比纯视觉置信度更贴合细粒度场景。

### 4.3 参数高效微调 PEFT（L2）

只训极少量参数，天然抑制过拟合与遗忘：

- **CoOp / Co-CoOp（Prompt Tuning）**：在文本塔前加可学习 prompt，视觉塔冻结。★ 首推，最贴合 CLIP、参数量最小。
- **LoRA**：在 ViT 的 Q/K/V 上插低秩矩阵。工程成熟，8GB 可跑。
- **Adapter**：Transformer 层间插小 MLP。
- **建议**：主攻 **CoOp 变体**（赛题参考列表里有 JoAPR = 清洗 prompt 的 CoOp 改进），LoRA 作备选。

### 4.4 鲁棒损失函数（L2）

- **GCE（广义交叉熵）**：在 CE 与 MAE 之间插值，对噪声标签更鲁棒。
- **SCE（对称交叉熵）**：CE + 反向 CE 组合，抑制错误标签的梯度。
- **ELR（Early Learning Regularization）**：用早期学习的「记忆化」正则，防止后期过拟合噪声。
- **标签平滑**：降低对硬标签的过度自信。
- 组合策略：`鲁棒损失 + 样本重加权` 通常 > 单一损失。

### 4.5 长尾分布处理（L3，复赛/半决赛关键）

- **类别重加权**：按类别样本数倒数加权 loss（class-balanced loss / LDAM）。
- **Focal Loss**：自动降权易分样本，聚焦难分/少样本。
- **重采样**：过采样尾类 / 欠采样头类（注意别引入额外数据）。
- **注意**：初赛均衡、复赛/半决赛长尾，方案要**跨阶段自适应**，不能只针对初赛调。

### 4.6 灾难性遗忘抑制（L3）

- **WiSE-FT**：微调后权重与预训练权重做凸组合 `w = α·w_ft + (1-α)·w_pretrain`，α≈0.5。**零成本、效果好、强烈推荐**。
- **L2-SP / 特征约束**：约束微调后的特征不要偏离 CLIP 预训练特征太远。
- **表征一致性约束**：同一图像不同增强下的特征保持一致（对比学习式正则）。

### 4.7 On-Policy Self-Distillation 自蒸馏（L2，抗噪正则 ★ 主推创新点）

**原理**：不依赖噪声硬标签，而是用**当前模型自身**的软预测做监督——对同一图像做两次不同增强，用一次预测去监督另一次输出（KL 散度）。属于 on-policy（无 EMA teacher，单模型自我监督）。

**为什么适合本题**：
- ✅ **单模型**：不引入第二个网络，天然规避「禁集成」约束（比 Co-teaching 双网络更安全）；
- ✅ **软标签抗噪**：模型自身概率分布比错误 one-hot 标签平滑、可靠；
- ✅ **细粒度友好**：软标签保留类别间相似性结构，正是细粒度识别需要的；
- ✅ **防遗忘**：自蒸馏约束特征不偏离 CLIP 预训练先验。

**三个坑，必须处理**：
1. **冷启动**：早期模型不准，on-policy 预测一开始就偏 → 前几个 epoch 纯 CE warmup，再引入自蒸馏；
2. **自我强化错误**：模型早期学到噪声模式会被自蒸馏放大 → 必须配合鲁棒损失 + 数据层滤噪；
3. **λ 调度**：自蒸馏损失从小到大学（linear ramp），避免盖过真实标签信号。

**落地（叠加在 CoOp 上，不推翻主线）**：
```
L_total = L_GCE/SCE(鲁棒CE) + λ(t)·L_KL( p(x1) ∥ p(x2) ) + 可选 WiSE-FT 约束
```
其中 x1、x2 为同一图像的两次增强，λ(t) 随 epoch 线性增大（或 warmup 后固定）。

## 五、创新点方向（差异化，冲复赛/半决赛）

1. **「CoOp + On-Policy Self-Distillation」抗噪框架（★ 主推）**：在参数高效微调框架下引入 on-policy 自蒸馏作噪声鲁棒正则，单模型自我监督、软标签抗噪，该组合在赛题参考论文中未见，差异化强。
2. **「CLIP 语义先验 + 噪声筛选」融合**：用文本-图像相似度做标签可信度校验，替代纯视觉置信度（TrustCLIP 思路：语义标签验证 + 可信梯度投影）。
3. **「Prompt 清洗」**：在 CoOp 基础上主动降低噪声样本对 prompt 学习的污染（JoAPR 思路）。
4. **「PEFT + 鲁棒损失 + OPSD」协同**：验证 PEFT × 鲁棒损失 × 自蒸馏的组合在噪声+长尾下的稳定性，形成可复现的最佳组合。
5. **跨阶段自适应**：设计对类别数/噪声水平/长尾程度不敏感的方法，靠复赛+半决赛的稳定性拿综合分。

## 七、工程实现要点

- **目录结构**（建议）：
  ```
  src/
    data/        # Dataset/Dataloader、噪声筛选
    models/      # CLIP 加载 + PEFT 模块
    losses/      # GCE/SCE/ELR/class-balanced/OPSD 自蒸馏
    train.py     # 训练入口（含噪声筛选，全程可复现）
    inference.py # 推理 → pred_results.csv → zip
  configs/       # yaml 超参
  ```
- **可复现性（硬性要求）**：噪声筛选必须在 `train.py` 里自动执行；固定随机种子；`requirements.txt` 锁版本。
- **提交格式**：`pred_results.csv`，两列 `图片文件名, 类别编号`（4 位补零），压缩为 zip。
- **算力**：CLIP ViT-B/32 + CoOp/LoRA 在 RTX 5070 Laptop 8GB 即可训练，基本零云端成本。
