# AIC 2026 赛题四技术路线

## 一、方案概述

本方案面向含噪标签、细粒度和长尾分布条件下的自然动植物图像分类任务，采用“CLIP ViT-B/32 先验保持 + 参数高效微调 + 噪声感知学习 + 类别原型约束 + 长尾校正”的单模型路线。

核心方法命名为 NRP-PEFT（Noise-Robust Prototype-calibrated Parameter-Efficient Fine-Tuning）。方案不依赖人工清洗，不依赖额外数据，不使用多模型集成，所有噪声筛选与权重更新均由程序自动完成。

官方数据规模为：初赛 500 类、103,218 个训练样本；复赛 750 类、148,695 个训练样本；半决赛 500 类、90,197 个训练样本。复赛和半决赛存在长尾分布，测试集标签不公开。

## 二、总体架构

```text
官方训练数据
    ↓
数据审计与类别映射
    ↓
冻结 CLIP ViT-B/32 提取初始特征
    ↓
类别原型构建与样本可信度估计
    ↓
鲁棒预热：分类头 + 鲁棒损失
    ↓
参数高效微调：LoRA/Adapter + EMA 教师
    ↓
原型约束 + 表征保持 + 长尾校正
    ↓
单模型推理
```

## 三、数据处理

### 1. 数据审计

- 使用 Pillow 统一读取和验证图像；
- 统计类别数量、图像尺寸、长宽比和异常文件；
- 记录重复图像与疑似近重复图像；
- 建立训练清单、测试清单和类别映射；
- 不进行人工删除，异常样本只通过自动权重机制处理。

### 2. 训练验证划分

从训练集内部建立固定随机种子的分层验证集。由于验证集也可能含噪，模型选择同时观察整体 Accuracy、可信子集 Accuracy 和 Macro Accuracy。

### 3. 类别名称兼容

官方材料明确训练数据按类别文件夹组织，但未明确是否提供自然语言类别名称。因此设计两种模式：

- 若只有数字或匿名类别编号：使用图像特征原型，不依赖文本信息；
- 若提供可靠类别名称：额外使用 CLIP 文本原型辅助初始化和置信度估计。

主方案必须在第一种模式下独立运行。

## 四、噪声标签建模

### 1. 类别原型

使用冻结 CLIP 图像编码器提取归一化图像特征 (z_i)，对每个类别计算鲁棒原型：

\[
p_c=Normalize(RobustMean\{z_i:y_i=c\})
\]

鲁棒均值可以采用截断均值、medoid 或小批量聚类中心，降低错误标签对原型的污染。

### 2. 样本可信度

对每个样本计算：

\[
r_i=\alpha s(z_i,p_{y_i})+\beta q_i+\gamma a_i-\delta d_i
\]

其中 (s) 为样本与标签原型的相似度，(q) 为分类头或教师模型置信度，(a) 为增强一致性，(d) 为样本与类别局部邻域的距离。

可信度被转换为连续样本权重，而不是直接删除样本：

\[
w_i=clip(Normalize(r_i),w_{min},1)
\]

样本分为高可信、中可信和低可信三档：高可信样本使用完整监督和原型约束；中可信样本降低监督权重并使用教师软标签；低可信样本保留低权重监督，主要使用一致性和表征约束。

## 五、模型设计

### 1. 主干网络

严格使用 CLIP ViT-B/32。默认冻结大部分参数，仅训练视觉 Transformer attention 投影层中的 LoRA 或轻量 Adapter、分类头，以及必要时最后若干层的 LayerNorm。

推荐实验顺序为：线性分类头、Adapter、LoRA rank 4/8/16、LoRA 加少量 LayerNorm。

### 2. 鲁棒分类损失

使用带样本权重的鲁棒损失：

\[
L_{cls}=\frac{1}{B}\sum_i w_iL_{robust}(p_i,y_i)
\]

候选损失包括 Cross-Entropy、Generalized Cross-Entropy 和 Symmetric Cross-Entropy。第一版建议使用 GCE 或 SCE，不同时堆叠过多复杂损失。

### 3. EMA 教师模型

维护学生模型的指数滑动平均作为教师：

\[
\theta_T\leftarrow\mu\theta_T+(1-\mu)\theta_S
\]

教师处理弱增强图像，学生处理强增强图像。中低可信样本使用教师软标签，高置信教师预测才转为尖锐伪标签，避免确认偏差。

### 4. 原型与表征保持

令微调特征为 (z_i')，冻结特征为 (z_i)，加入：

\[
L_{feat}=1-cos(z_i',z_i)
\]

并使用类别原型约束：

\[
L_{proto}=1-cos(z_i',p_{\hat y_i})
\]

总损失为：

\[
L=L_{cls}+\lambda_sL_{soft}+\lambda_pL_{proto}+\lambda_fL_{feat}
\]

各辅助损失从小权重开始逐步启用。

## 六、长尾处理

针对复赛和半决赛：

1. 使用平方根逆频率进行类别感知采样；
2. 使用 effective-number 或平方根逆频率进行类别重加权；
3. 训练后期比较 logit adjustment；
4. 将噪声权重和类别权重分开计算：

\[
w_i^{final}=w_i^{noise}\times w_{y_i}^{tail}
\]

最终权重需要归一化并设置上限，防止少数类噪声样本被过度放大。

## 七、训练流程

### 阶段一：基线

冻结 CLIP，仅训练线性分类头，建立基础 Accuracy、Macro Accuracy 和类别混淆矩阵。

### 阶段二：原型预热

提取冻结特征，计算类别原型和样本可信度；使用高、中可信样本训练分类头，并比较 CE、GCE 和 SCE。

### 阶段三：鲁棒 PEFT

加入 LoRA 或 Adapter、动态噪声权重、EMA 教师、软标签和表征保持约束。

### 阶段四：长尾优化

加入类别感知采样和 logit adjustment，重点比较头部、中部和尾部类别表现。

### 阶段五：最终验证

固定随机种子和配置，在当前阶段允许使用的全部训练数据上重新训练；测试集只用于最终推理。

## 九、工程与算力方案

实现应支持单卡运行、多卡加速、AMP、梯度累积、断点续训和特征缓存。A100 用于主实验和大规模消融，AutoDL 用于批量实验；方案不依赖特定平台。

建议模块划分为：数据审计与数据集、CLIP 与 PEFT、原型与 EMA、鲁棒损失、长尾损失、训练验证、推理和配置管理。

必须保存随机种子、配置、类别映射、训练日志、模型权重和实验版本信息。

RL/OPD/OPSD/MOPD 方向适合用于后续创新：将样本选择、标签信任程度和教师/学生权重看作动态决策问题。但第一版应先完成“原型可信度 + EMA + PEFT”基线，再验证 RL 模块是否带来稳定增益。

## 十一、主要风险与应对

1. 难例被误判为噪声：使用连续权重，不做硬删除，并对尾类采用更宽松阈值。
2. 教师模型确认偏差：延迟启用伪标签，仅在高置信时锐化，并定期用冻结特征重新校准。
3. 长尾校正损伤整体准确率：同时观察整体 Accuracy 和 Macro Accuracy，必要时关闭 logit adjustment。
4. LoRA 容量不足或过拟合：比较 Adapter、不同 LoRA rank 和 LayerNorm 解冻策略。
5. 类别名称不可靠：文本原型保持为可选模块，主方案不依赖它。

## 十二、最终技术主线

第一优先级：冻结 CLIP + 线性分类头基线。  
第二优先级：LoRA/Adapter + GCE/SCE。  
第三优先级：原型可信度动态加权 + EMA 教师。  
第四优先级：表征保持 + 长尾校正。  
第五优先级：在主线稳定后，再引入 RL 驱动的动态样本选择或信任策略。

该路线在满足 CLIP ViT-B/32、单模型、无额外数据和可复现等约束的前提下，兼顾竞赛成绩、方法创新性和技术答辩完整性。
